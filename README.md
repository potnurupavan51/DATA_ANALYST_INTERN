# Alt Mobility SQL Queries

This repository contains SQL queries for analyzing the Alt Mobility dataset. The queries cover various aspects of the business including:

- Order Status Analysis
- Sales Data Analysis
- Customer Order Trends
- Payment Analysis
- Customer Retention Analysis

## Directory Structure

- `sql/` - Contains all SQL query files
  - `SQLQueries.sql` - Main SQL queries file

## Query Categories

1. **Order Analysis**
   - Order status distribution
   - Total and average sales
   - Monthly sales trends
   - Customer order patterns

2. **Payment Analysis**
   - Payment status distribution
   - Payment method analysis
   - Payment failure rates
   - Payment trends over time

3. **Customer Analysis**
   - Customer retention metrics
   - Repeat customer analysis
   - Cohort analysis

## Database Information

These queries are designed to work with the Alt_mobility database.
